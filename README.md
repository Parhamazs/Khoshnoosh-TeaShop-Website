# خوشنوش (Khoshnoosh) - پلتفرم جامع تجارت الکترونیک دمنوش‌های گیاهی و ارگانیک

پلتفرم پیشرفته و یکپارچه فروشگاه اینترنتی دمنوش‌های گیاهی، ارگانیک و چای‌های اصیل ایرانی با معماری تمیز و کاملاً آماده تولید (Production-Ready).

## ساختار معماری پروژه (Architecture)

این مخزن به دو بخش اصلی مستقل تقسیم شده و از طریق Nginx Reverse Proxy و Docker Compose هماهنگ می‌شود:

```
├── backend/                  # وب‌سرویس و هسته تجاری جنگو (Django 5 + DRF + Celery)
│   ├── apps/
│   │   ├── accounts/         # مدیریت کاربران، اعتبارسنجی JWT و آدرس‌ها
│   │   ├── products/         # محصولات دمنوش، ویژگی‌های گیاهی، طبع، دسته‌بندی و برچسب‌ها
│   │   ├── cart/             # سبد خرید کاربری و مهمان
│   │   ├── orders/           # ثبت و پردازش سفارش، وظایف ناهمگام Celery
│   │   ├── payments/         # ماژول درگاه پرداخت بانکی و شبیه‌ساز امن ساندباکس
│   │   ├── blog/             # وبلاگ آموزشی، طب سنتی و سلامت روان
│   │   ├── reviews/          # سیستم امتیازدهی و نظرات کاربران
│   │   └── wishlist/         # لیست علاقه‌مندی‌ها
│   ├── khoshnoosh/           # تنظیمات مرکزی، Celery، WSGI و مسیریابی
│   ├── seed_data.py          # اسکریپت بارگذاری داده‌های واقعی دمنوش‌ها
│   ├── requirements.txt      # پیش‌نیازهای پایتون
│   └── Dockerfile            # ایمیج اختصاصی بک‌اند با Gunicorn
│
├── frontend/                 # رابط کاربری وب تک‌صفحه‌ای (Vue 3 + Vite + Pinia + Tailwind)
│   ├── src/
│   │   ├── api/              # لایه سرویس ارتباطی با Axios Interceptor
│   │   ├── stores/           # استورهای Pinia (احراز هویت، سبد، محصولات و ...)
│   │   ├── views/            # تمامی صفحات عمومی و اختصاصی کاربر
│   │   ├── components/       # کامپوننت‌های ماژولار و بهینه‌سازی شده برای زبان فارسی و RTL
│   │   └── router/           # روت‌های SPA با گارد احراز هویت
│   ├── nginx.conf            # تنظیمات سرور استاتیک فرانت‌اند
│   └── Dockerfile            # ساخت بهینه چندمرحله‌ای (Multi-stage Build)
│
├── nginx/                    # ریورس پروکسی سراسری Nginx (پورت 80)
│   └── nginx.conf
├── docker-compose.yml        # ارکستراسیون کامل سرویس‌ها (Postgres, Redis, Backend, Celery, Frontend, Nginx)
└── README.md
```

## سرویس‌های راه‌اندازی شده در داکر (Docker Services)

1. **db (PostgreSQL 15)**: پایگاه داده رابطه‌ای با ذخیره‌سازی ماندگار روی volume اختصاصی
2. **redis (Redis 7)**: صف پیام برای وظایف پس‌زمینه و کش
3. **backend (Gunicorn + Django)**: سرویس‌دهنده API های RESTful
4. **celery (Celery Worker)**: مدیریت فرآیندهای آسنکرون (ارسال پیامک و ایمیل تایید سفارش)
5. **celery-beat (Celery Periodic Tasks)**: زمان‌بند خودکار وظایف دوره‌ای
6. **frontend (Nginx + Vue 3)**: ارائه‌دهنده SPA
7. **nginx (Gateway / Reverse Proxy)**: هدایت ترافیک درگاه 80 به فرانت‌اند، API و فایل‌های مدیا/استاتیک

## نحوه راه‌اندازی و اجرا با Docker Compose

### گام ۱: آماده‌سازی متغیرهای محیطی
فایل نمونه متغیرهای محیطی را کپی کنید:
```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

### گام ۲: بیلد و اجرای کانتینرها
تنها با یک دستور تمام سرویس‌ها ساخته و فعال می‌شوند:
```bash
docker compose up --build -d
```

### گام ۳: اجرای مایگریشن‌ها و ورود داده‌های اولیه دمنوش‌ها (Seed Data)
کانتینر بک‌اند به صورت خودکار مایگریشن‌ها و داده‌های اولیه را اعمال می‌کند. در صورت نیاز به اجرای دستی:
```bash
docker compose exec backend python manage.py migrate
docker compose exec backend python manage.py shell < seed_data.py
```

### گام ۴: دسترسی به سرویس‌ها
- **فروشگاه دمنوش خوشنوش (Frontend)**: [http://localhost](http://localhost) یا [http://localhost:3000](http://localhost:3000)
- **مستندات Swagger / OpenAPI**: [http://localhost/api/docs/](http://localhost/api/docs/)
- **پنل مدیریت جنگو (Django Admin)**: [http://localhost/admin/](http://localhost/admin/)
  - نام کاربری: `admin@khoshnoosh.ir`
  - رمز عبور: `Admin@123456`
- **حساب کاربری نمونه خریدار**:
  - نام کاربری: `sara@example.com`
  - رمز عبور: `User@123456`

## امکانات کلیدی فروشگاه خوشنوش

- **پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)**: طراحی چشم‌نواز با فونت Vazirmatn، اعداد فارسی و پالت رنگی الهام‌گرفته از طبیعت و گیاهان دارویی (`#4F6F52`, `#A9B388`, `#FEFAE0`, `#DDA15E`).
- **فیلترینگ چندبُعدی تخصصی دمنوش**:
  - فیلتر بر اساس طبع سنتی (گرم و خشک، گرم و تر، معتدل، سرد)
  - فیلتر بدون کافئین / ارگانیک ۱۰۰٪
  - فیلتر دسته‌بندی و محدوده قیمت
  - مرتب‌سازی بر اساس محبوب‌ترین، تازه‌ترین و ارزان‌ترین/گران‌ترین
- **مشخصات جامع گیاهی و دارویی**: ترکیبات دمنوش، خواص و فواید درمانی، راهنمای دم‌آوری، موارد احتیاط و منع مصرف.
- **سبد خرید پویا و کشویی**: افزودن، کاستن، محاسبه خودکار هزینه ارسال (رایگان برای سفارش‌های بالای ۳۰۰ هزار تومان).
- **درگاه پرداخت آزمایشی (Sandbox)**: شبیه‌سازی مرحله پرداخت، ثبت کد رهگیری، شماره کارت ماسک‌شده و صدور رسید دیجیتال.
- **پنل کاربری و پیگیری سفارشات**: مشاهده وضعیت سفارشات (در حال بسته‌بندی، ارسال شده، تحویل شده)، مدیریت آدرس‌های پستی و لیست علاقه‌مندی‌ها.
- **وبلاگ و مقالات طب سنتی**: مقالات علمی و سنتی با تخمین زمان مطالعه و دسته‌بندی موضوعی.
